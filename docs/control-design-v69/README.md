# 手機控制按鈕三案比較

這是使用者要求先確認的靜態視覺稿，沒有掛載或修改正式遊戲。

- `comparison.html`：三案直向與橫向示意。同場景、人物、尺寸與狀態，方便比較造型與配色。
- A 街頭漫畫：厚墨框、暖紙底、立體方圓鍵。
- B 印刷快打：深色操作底、俐落方鍵、奶油色招式票券。
- C 糖紙街機：圓形街機鍵、粉彩票券、薄荷底。

共同內容：五個功能鍵同尺寸；三招只顯示名稱與冷卻；助拳示範 42% 底向上充能；揪團示範滿氣可用；不含第二條水平氣條。這是街道模式示意，並不代表在 VS 新增跳鍵。CSS 側轉沿用橫向配置，但此稿尚未執行實際側轉或遊戲觸控。

## 本機檢視

以本機靜態服務提供專案根目錄，開啟 `/docs/control-design-v69/comparison.html`。瀏覽器必須能載入既有 `dist/` 素材與渲染模組。

若既有預覽只提供 `dist/`，可將此 HTML 複製成 `dist/qa-control-design-v69.html`。這是獨立檢視頁，不要加入 `index.html`。頁面會自動選擇同層的遊戲素材，亦支援 `?assetBase=...` 指定素材路徑。

- `?scheme=a`、`?scheme=b`、`?scheme=c`：只看單一方案。
- 全方案建議 1240px 以上寬度，直向三案並排。
- 橫向示意為 696 × 332px；直向為約 332 × 600px。
- 等 `window.controlDesignReady === true` 再截圖。
- `window.inspectControlDesign()` 回報六個示意的五鍵尺寸、元件重疊與超出手機框的項目。

## 驗證範圍

此稿不啟動 Phaser、不載入 `game.mjs`，也不修改 localStorage 或其他遊戲狀態。僅使用既有美術渲染器繪製靜態場景。HTML 內模組已做 JavaScript 語法檢查；實際畫面與幾何交由共用瀏覽器檢查，尚不代表正式遊戲的三方向回歸通過。

正式實作前仍需使用者選定方案，之後再驗證 320px 直向、短橫向、CSS 側轉、各種充能狀態與七角色完整招名。
