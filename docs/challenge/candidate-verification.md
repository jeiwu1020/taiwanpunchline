## 已完成的內容

- 四章共用視窗幾何、轉向穩定等待、safe area 與觸控 epoch。畫面未穩定時暫停輸入與戰鬥；不使用固定手機 Y 偏移補丁。第一章保留 Phaser 呈現接頭，第二至四章使用同一章節 UI 接頭，兩者都接同一生命週期。
- 第二至四章的轉場控制抽成同一內容配置式控制器。第一章由轉接器使用同一持久化規則，沒有另一套 XP 或首通保存權威。新增章節接口見本目錄的 foundation-contract.md。
- 出怪與助拳會預先保留鏡頭空間，減少突然拉遠。背景採原密度、有界快取，不降低 DPR 或換低畫質素材；落地後再次跳躍可重用同場景快取。
- 總覽、出戰準備、能力雷達與技能樹使用既有奶油紙、墨綠粗框及漫畫按鈕。保存配置、開始／接續、邊界整備及重試是不同明確操作。戰鬥中能力唯讀，調整先確認重試，整場 Boss 比分歸零。
- 七位角色具有小幅取捨的天生能力，一般對戰、練習與挑戰一致。技能點只作用於挑戰，每角有同額獨立配點。雷達呈現實際天生／已保存／草稿能力，不再用投入點數冒充能力。
- 街道路段保留氣勢、助拳與揪團；小、大 Boss 入場重置，三戰兩勝每小局沿用原重置。重試普通怪可再領 XP，首通獎每槽只領一次。
- 同幀多個怪物獎勵與路段完成為一次保存。必須寫入且讀回成功才切場；失敗保持原畫面並允許重試。多分頁、重置後舊草稿與延遲回呼不能覆寫新進度。
- 新存檔使用獨立 v4 鍵與三槽。單槽重置／還原需確認，先建立並讀回復原備份，只改指定槽，不動其他槽與設定。依本次決定，不自動遷移舊測試存檔；舊資料並未刪除。
- 測試模式是純記憶體配置，全角色可選但不記錄進度；不會將測試配置保存到正式槽。
- 第四章完成後保存並回總覽，第五章明示尚未開放。

## 瀏覽器驗證與界線

已使用受支持的雲端 Chromium 預覽驗證真實首頁與章節入口、正式 v4 保存、重新進入、唯讀能力、明確重試、總覽往返及第四章出口。另以真共用模組與 CSS 的瀏覽器隔離頁驗證四章幾何、轉向、命中、保存失敗與退出鎖定；這些隔離頁與完整遊戲流程分開記錄，不能互相替代。

完整第一章另在 390×844 直式、同尺寸側轉 90°、844×390 原生橫向各驗一次：三組均 ready，27 個控制中心及 3 個保存欄均在框內且命中。實際載入的 125 個本地 JS／CSS 沒有同路徑多版本。這些是桌面 Chromium 中的真遊戲頁，不是實體手機。

第二至四章以真 HTML 與未替換的正式 playable 模組、隔離存檔 prefix，在相同三種方向分別驗開場與首段街道，共 18 組：全部 ready，保存欄與漫畫下一格命中；9 組街道各 9 個可見控制中心均在框內且命中，沒有觀察到應用 JS 錯誤。這不代表每一場 Boss、每一張結算畫面都已用這三種方向人工玩過。

仍未驗證：

- 實體 iPhone Safari、PWA／應用內容器、Android Chrome 的 compositor、瀏覽器工具列收合、多指按住旋轉、觸覺與實際手感。
- 長時間實機 FPS／耗電／記憶體及音訊實際聽感。快取計數和 Canvas draw 呼叫時間不能當作實機 FPS。
- 第一章 Phaser 與後章 Canvas 的呈現接頭仍不同；本輪沒有改動既有低幀率時間步進政策。共享的是視窗、輸入、能力、保存與轉場規則，不是把全部渲染程式改成同一個引擎。
- 瀏覽器下載檔案再以系統檔案選擇器匯入的完整往返；匯出／匯入格式、控制器交易與失敗防護已通過程式測試。
- 人類玩家的角色公平性與難度調整。七角數值是初步試行值，原有 VS／街道部分招式細節差異仍保留，沒有宣稱所有模式的全部招式效果完全相同。
