# 第 65 版實測問題修正規格

基準：私人網站第 65 版，來源 `29f347d8305c87d15d04033c8c6e0a0a2fdc8a52`。日期：2026-11-11。

## 使用者要求

- VS 穩定視野在桌面、手機原生橫向及側轉左右移動時，不應突然跳接或切成遠景。包含議場及挑戰頭目對戰。
- 街道的穩定／動態視野在手機直向與側轉應更接近人物，並修正跳接。不得改碰撞、出怪、人物素材或戰鬥規則來掩蓋相機問題。
- 桌面開場漫畫一頁顯示，不出捲軸。上一格、下一格、重看及關閉使用一致的漫畫按鈕語彙。
- 挑戰總覽、出戰準備、存檔管理在同一頁框切換。整備仍需草稿、取消與確認；戰前及戰鬥中檢視保留各自語意。側轉時整備不應過大或阻礙觸控捲動。
- 存檔管理即使有捲軸，也要與總覽維持相同版面寬度。
- 整備確認底列完整不透明、沒有捲動內容透出或露到下緣。
- 暫停的「查看角色能力」與其他選單按鈕形狀一致，配色不同。
- 手機直向的說明文字下移，不遮擋秒數。
- 手機直向頂列順序為「拳民開講」、保存狀態、首頁及其他按鈕，一行排列；窄螢幕不可重疊或不能操作。
- 開始挑戰不能短暫顯示舊 VS 議場；資料保存、場景設定及實際畫面完成後，才移除前一個介面。

## 不變條件

- 四章共用視窗、轉向、輸入、安全區與介面基礎，不複製四套修補。
- 保留既有奶油紙、墨綠粗框、漫畫風格、素材、招式、劇情及存檔資料。
- 不改 v4 保存格式、經驗、首通、角色能力及沿途資源規則。
- 在獨立候選修正；沒有另行發布許可，不更新正式網站。
- 已有完整來源備份及第 64、65 版回退資料保留。來源備份不等同玩家瀏覽器存檔。

## 驗收與限制

1. 先以未修改第 65 版重現根因及失敗案例，再驗修正後實際行為。
2. 鏡頭使用真正共用模組與各章呼叫端的連續 frame trace，比對 pan、zoom 及人物實際畫面高度。測走至邊緣、反向、碰撞、助拳、出怪、擊退、暫停與方向切換，不以靜態圖片聲稱平順。
3. 幾何測量包含桌面 1280×720、390×844 直向／側轉、844×390 原生橫向，頂列另涵蓋 320、390、430 寬度。測量真 DOM 及共用 occlusion 函式，不只用人工矩形。
4. 整備草稿取消、切換頁籤、保存失敗、快速重複點擊、退出、新導航與過期回呼均不可遺失或覆寫進度。
5. 桌機漫畫文字完整可讀、按鈕可達且一頁顯示；短手機長文保留必要的垂直閱讀捲動，不產生非預期水平溢出。整備可捲動而固定確認列不漏底；所有方向保留原生命中及正確側轉拖曳。
6. 凍結候選後跑完整測試、建置、瀏覽器主要流程及來源／素材比對，完整備份重新讀回還原。

桌面 Chromium 的手機尺寸及側轉測試不是實體手機。iPhone Safari／PWA／應用內容器、Android、硬體多點觸控與真人平衡另列未驗，不擴大宣稱。
