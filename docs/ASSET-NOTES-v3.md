# 漫畫招式 V3：素材、來源與範圍

本版為私人 Sites 原型，非 GitHub taiwanfighter 專案整合。沒有修改 GitHub main，也沒有新增 Codex 任務。玩法判定 core.mjs 保持原檔；本次修改角色繪製、道具、示範檢視器與原聲播放。

## 新美術

使用同風格的生成漫畫分件：王世堅暖桃色握杯右手、炭灰西裝分件、蜷身翻滾；韓國瑜藍綠西裝分件、連貫拉弓上身及放弦上身；兩人遠側左掌；墨鏡、金幣、箭、水花。原四張漫畫頭像沿用。

- Wang 握杯右手沿用已接受的手背遮杯構圖，膚色變暖、接近臉部。
- 近側右手／遠側左掌各自維持層級。遠側整臂先畫，近側手臂後畫。兩節手臂以固定長度 IK 帶動，不把掌部任意翻面。
- 兩人出拳、防禦、移動、跳躍與原有三招均改用新素材。
- 翻滾採蜷身整圖切換並旋轉，拉弓採上身關鍵圖切換，仍是 2D 漫畫而非完整 3D 骨架。
- 翻面為整張角色水平鏡像，非另一套真正反向透視。
- 箭離弦時以裝飾位移銜接弓上箭，再回到既有落點；紅色地面提示與 core 判定未改。

全部新貼圖由生成 PNG 轉換成無損 WebP，轉換前後 RGBA 像素完全一致。沒有用腳本改畫、改膚色或清除背景。放弦原圖曾有半透明底，已以圖像編修重新產生乾淨透明版。原始生成 PNG 保存在工作區，不另放進網站下載負擔。
