# V5 first new-roster batch

Original generated transparent head portraits for Ma Ying-jeou, Su Tseng-chang and Huang Kuo-chang; a three-row costume atlas (navy/blue tie, brown/orange tie, gray/burgundy tie); and original handshake-right-forearm, desk, folder and flying-page prop atlas. Existing generated Wang/Han atlases were style/limb-identity references. All PNGs were converted to lossless exact WebP with RGBA byte-equality verification. Background alpha samples in atlas gutters are zero; no script redrew, recolored or removed backgrounds.

The three new costumes attach to the same constrained arm/knee/ankle pose system as V4. Near arms use dorsal right hands; rear arms use palmar left fists behind the torso. Handshake uses a separate anatomically consistent open right forearm. Desk and folder draw before the near hand so grip/contact can occlude the prop. New motion is procedural cutout animation, not photo-realism or a 3D rig.

New head assets are1254×1254; costume/prop atlases1536×1024. Five new images add approximately7.5 MiB transfer and30 MiB decoded pixels. Older devices may be slower. Existing Han audio is byte-identical; no new actual voices were added. New characters use existing synthesized effect sounds, not voice imitation.
