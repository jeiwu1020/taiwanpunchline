# V4 art assets

`dist/assets/limbs-v4.webp` is an original generated transparent 1536×1024 two-row atlas: Wang charcoal suit above, Han teal suit below. Each row contains upper trouser leg, lower trouser leg/shoe and left-palmar fist/forearm. References were existing generated Wang/Han costume and the approved left-palm artwork. Prompt required separate rounded joint caps, consistent warm face-matching skin, correct left palmar thumb side and no right dorsal-hand anatomy. Source PNG was visually inspected and converted losslessly to WebP with exact RGBA equality. No external stock art added.

Implementation uses fixed-length two-bone IK (thigh35/shin40 units), overlapping cloth caps, separate shoe ankle placement and existing coat occlusion. Arms retain fixed handedness. These are 2D cutout illustrations, not a new 3D model or full anatomical rig.

All V3 images, real Han short clip, source attribution and unconfirmed reuse-rights limitation remain as documented in ASSET-NOTES-v3.md. Private test use only; no public/commercial-rights claim.
