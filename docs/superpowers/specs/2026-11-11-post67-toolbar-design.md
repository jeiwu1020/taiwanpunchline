# 第 67 版後的直向工具列與保存狀態修正

使用者已同意窄螢幕保留黃色「拳」招牌、縮短保存提示、單行且按鈕好按；並確認保存字樣殘留發生在退出街道後的一般 VS。此次以 #67 commit `806f00c3f16d51708c7bd52f4da8ca57825f7b89` 為基線，不含另分支的 Phaser 試接。

## 已證實原因

挑戰直向 CSS 明確隱藏 .brand-icon，按鈕為最小 30×32px；這套規則在 #66 已有。endChallenge 清除挑戰物件及模式，但未重新同步保存格。原程式的記憶體存檔測試已重現一般 VS 留著「進度已保存」。

## 採用設計

- 四章挑戰的手機直向沿用一行「品牌／保存狀態／四個工具鍵」，黃拳招牌恢復。320、360px 寬僅顯示黃拳標，390、430px 另顯示完整字標；品牌的完整可存取名稱始終保留。
- 品牌入口、保存入口及四個主要按鈕都至少 44×44 CSS px。窄螢幕使用 44px 品牌格、44px 保存格、其餘空間四等分工具格；390px 以上品牌格 104px。字級不靠縮至10px換空間，短標籤用12px。
- 原按鈕文字／狀態語意保留，直向視覺短標籤用首頁／總覽、聲音開／聲音關、暫停／繼續、設定。共用 helper 從實際 button 內容與 aria-pressed 同步 data-short-label，不複製四套狀態邏輯。
- 保存短狀態為已保存／保存中／需處理／不保存；完整保存說明及備份入口仍保留，錯誤不能為了整齊被藏掉。
- 挑戰直向 header 高44px、top仍6px；HUD top70px 與其高度、控制區及鏡頭幾何保持 #67，不挪動使用者滿意的人物尺度。若實際幾何不夠，先報告，不偷縮回小按鈕。
- 正常退出挑戰後立即同步保存格，回一般 VS／練習／標題不得留著挑戰保存入口。未完成保存或復原時仍遵守原有阻擋流程，不新增取消保存／重置／寫入。
- 桌機、橫向、側轉原有工具列外觀不變；只有視覺短標籤 CSS 在 touch portrait 生效。共同狀態 helper 可讀所有模式，但不改遊戲行為。
