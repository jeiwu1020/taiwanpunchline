# Four-limb movement and crouch, first version

User-approved scope: extend existing Wang/Han private prototype with active use of both arms and legs and a held crouch. Preserve existing attack hit rules, damage, cooldowns and timing. Do not claim crouch evades attacks. No new politicians, new Codex tasks, GitHub changes, public sharing or new paid services.

Chosen approach: keep J/held attack, visually cycle left jab, right punch, front kick within the same basic-attack rule; give the other arm guard/counterbalance poses. Bend knees for stride, jump, landing, kick and crouch using suitable generated pieces. Keep accepted right drinking-hand anatomy and same skin style. S/down/held crouch stops horizontal movement while grounded and idle; back+crouch keeps existing guard. Jump or successful attack exits crouch; crouch cannot cancel attacks/stun/cooldowns or change foot-root y/hitboxes. Holding down resumes crouch after the action. Touch layout retains attack and all six character specials without overflow at 320x568/667x375.

Alternatives considered: independent kick button adds unnecessary mobile controls; high/low dodge combat changes balance and collision rules beyond this first version. Both deferred.

Acceptance: deterministic regressions, fresh source review, normal/mirror visual review of all new joints and hand poses, phone-size UI and held-input cancel flows; deploy existing owner-private Site only after checks. Clearly label crouch as posture/crouch guard, not an evasion mechanic.
