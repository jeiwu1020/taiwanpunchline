> Implement within the existing authorized dot cloud task; no new external Codex chat.

**Goal:** Give the player a usable settings and move-guide interface without changing combat.
**Architecture:** Isolated preference store, move-demo renderer, and settings view; existing game owns pause/input/audio integration and dialog geometry.
**Tech Stack:** Existing ES modules, Canvas 2D art renderer, Phaser game, CSS, node:test.
**Spec:** ../specs/2026-11-07-settings-design.md

## Constraints
- Reuse the existing owner-private Site and preserve V26 backup and original V22.
- No new music, campaign, progression, hit rules or animation changes in battles.
- Retain exact approved Chen audio and all source/history information.

## Review Focus
- Corrupt/unavailable storage must not prevent play.
- Rapid move/character/tab changes must stop stale previews and spoken phrases.
- Dialog keyboard actions must not trigger combat or resume in the background.
- Narrow landscape/sideways dialogs must keep tabs, content and close reachable.
- Independent channels and quick master mute must remain synchronized after reload/reset.
