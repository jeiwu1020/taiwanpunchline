# V19 Arena Implementation Plan

**Goal:** make the existing private comic fighter clearer, more theatrical and playful.
**Architecture:** isolated core/UI changes, parent integrates a small presentation module and a single generated background.
**Tech Stack:** existing Phaser3 Canvas, ES modules, SVG/CSS, built-in imagegen.
**Spec:** docs/qa-v19/design.md.

## Constraints
No paid generator or external API. No GitHub main. No new controls/modes. Preserve audio provenance, existing source identity and private audience.

## Review focus
- Simultaneous pickup may not favor actor iteration order.
- Throw acceptance, second hits, grabs and KO must remain fair.
- Scene décor and held-item indicators must not hide faces or target markers.
- Full/half/tiny cooldown sectors and phone result controls must remain legible.
- Pause, stale audio callbacks, scene teardown and bounded object pools must not leak.

## Tasks
- [ ] Core worker: failing item/guard tests, minimal rules implementation, complete old and new tests.
- [ ] UI worker: failing sector/label/status tests, SVG wedges and responsive HUD, regression suite.
- [ ] Parent: built-in generated chamber, pure camera geometry tests, bounded ambient/object presentation and gameplay integration.
- [ ] Independent review and fixes, official browser actual mobile/desktop/sound/item/camera QA.
- [ ] Remove temporary diagnostics, preserve asset hashes, source helper package and owner-private native deployment.
